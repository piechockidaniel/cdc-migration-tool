Features

  • Real-time CDC Monitoring: Continuously monitors source database for changes
  • Flexible Mapping: Column-to-column mapping with transformation support
  • Working Sets: Manage multiple synchronization workflows
  • Data Quality Verification: Compare source and destination data integrity
  • Event History: JSON-based logging of all CDC events
  • Live Monitoring: WebSocket-based real-time event streaming

Quick Start

  1. Go to Administration to configure source and destination connections
  2. Enable CDC on the source database and required tables
  3. Create table mappings between source and destination
  4. Create a working set and activate it
  5. Go to Operations to start synchronization
  6. Monitor progress in Monitoring section
